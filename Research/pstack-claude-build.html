pstack-claude · build path

pstack builds through one recipe: design, delegate, verify, then PR.

The Feature playbook is the build loop. Bigger work wraps it: figure-it-out designs a custom recipe, and the Autopilots and Orchestrate give each PR its own owner.

Where build lives

Four recipes write code; bigger playbooks run them per PR

Design

architect replaces a written spec with raced type sketches

Delegate

The lead never writes the code; each writer gets its own worktree

PR

Every recipe ends with the same cleanup and a ready PR

Autopilot

Autopilot-full: one owner per PR, a swarm verdict per round, your click to merge

vs /autopilot:build

Same arc, different checks: autopilot reviews documents, pstack races designs and drives the app
